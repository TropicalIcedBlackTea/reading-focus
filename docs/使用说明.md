# 文献专注 · 使用说明 1.1

解压发行包后，双击 **文献专注.exe**。适用于 Windows 10 / 11 和 .NET Framework 4.8，免安装。

## 开始、暂停与结束

选择 25、45、60 分钟，或在「自定义」中输入 1–180 分钟，点击「开始专注」。窗口收起为迷你模式并保持置顶；拖动顶部可移动位置，靠近屏幕边缘会自动贴边。

- 迷你窗口右上角的暂停按钮暂停计时，窗口展开；「继续专注」恢复计时并重新收起。
- 需要提前结束时，先暂停，再点击「结束本轮」。已读时间、单词和笔记都会保留。
- 时间到后自动结束并展开本轮结果；提示音可在标题栏右侧开关。
- 计时中不能直接结束或退出，需要先暂停。

窗口获得焦点时，空格开始或暂停，Esc 暂停；输入笔记时这两个键用于编辑。电脑睡眠期间倒计时照常进行，离开前请先暂停。

## 专注保护

仅在**计时进行中**生效。允许的应用：Zotero、Windows 文件资源管理器、常见浏览器，以及计时器本身。

- 点击「开始专注」或「继续专注」时，屏幕上其他应用的窗口会立即最小化。
- 计时期间切到其他应用，窗口会被最小化，计时器轻跳并闪烁红框，迷你窗口显示被最小化的应用名称。
- 不会关闭任何应用；暂停或结束后不再限制，可以自行恢复窗口。

系统锁屏、权限确认和安全界面不受影响；以管理员身份运行的应用可能因 Windows 权限限制无法最小化。

## 章节与每日统计

三个方框从左到右代表**引言、模型、发现**，读完一节勾选对应方框；误勾可以取消。「下一篇」保留已读部分并开始记录下一篇论文，不中断计时。

未计时时，窗口顶部显示今日阅读分钟数和三类章节完成数。只统计实际计时时间，暂停不计入；记录按电脑本地日期跨次保留。

## 笔记

点击「笔记」（迷你窗口中为笔记图标）展开文本框，计时继续进行；再次点击收起，内容保留。开始前写下的内容会带入下一轮。本轮结束时展示笔记，并导出 **本轮笔记.txt** 与 **本轮汇总.txt**；重新打开程序仍可查看上一轮。

## 单词与内置词典

计时期间，在允许的阅读应用中选中英文单词并复制，单词即加入本轮词表，释义随即显示在窗口中。

- 释义来自内置学术词典，不联网。词典侧重论文常用词：学术词表、研究方法与统计 / 计量术语、经济与社会科学常用词和常见缩写。
- 复数、时态、比较级和英式拼写归并到词条原形，例如 estimated → estimate、behaviour → behavior、hypotheses → hypothesis。
- 跨行选中同样可以识别：行尾连字符加换行（`hypo-` / `thesis`）、被空格或换行拆开的单词、PDF 连字（ﬁ、ﬂ）、软连字符、行尾脚注数字都会被还原。复合词（如 cross-sectional）保留连字符。
- 词典未收录的单词同样加入词表，标记为「词典未收录」。
- 只接收单个英文词；句子、数字、网址、中文和图片会被忽略。同一轮重复复制同一词只保留一条，并再次显示释义。
- 暂停期间不收集新词。

## 导出与扇贝单词

本轮结束后，文件自动保存在程序旁的 **词表\日期\本轮目录**；程序目录不可写时改用本地应用数据目录。点击「打开导出文件」打开该文件夹。

- **纯单词-扇贝用.txt**：每行一个词，包含词典未收录的词；也可点击「复制单词」。
- **中英词表.csv**：单词、中文释义、是否收录、论文序号与收集时间。
- **中英词表.tsv**：无表头，每行为英文、制表符和中文，只包含有释义的词。
- **本轮笔记.txt**：完整笔记。
- **本轮汇总.txt**：本轮阅读时长、单词与笔记。

扇贝当前 App 的文件导入入口尚未验证，这里提供纯单词 TXT 和复制功能，供其支持的添加方式使用。

## 本地记录

设置保存在 %LOCALAPPDATA%\ReadingFocusTimer\settings.xml，阅读统计、笔记与单词保存在同目录的 reading-data.xml，并保留上一份备份。程序不联网，没有账号、开机自启、遥测或自动同步。1.0 版本中在线翻译失败的单词，升级后会自动改用内置词典查询。

发行包只包含程序和说明，不包含任何个人词表、笔记或阅读数据。源码构建与检查方法见仓库 README.md。
