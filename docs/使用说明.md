# 文献专注 · 使用说明 1.0

解压发行包后，双击 **文献专注.exe**。适用于 Windows 10 / 11 和 .NET Framework 4.8，免安装，不需要 Python 或开发工具。

## 开始、暂停与结束

选择 25、45、60 分钟，或自定义 1–180 分钟，点击「开始专注」。窗口自动进入迷你模式，并始终置顶。拖动顶部可以移动位置，靠近屏幕边缘会自动贴边。

- 点击 **Ⅱ** 暂停，窗口恢复正常大小，同时解除专注保护并暂停收集单词。
- 点击「继续专注」恢复计时，自动返回迷你模式。
- 需要提前结束时，先暂停，再点击唯一的「结束本轮」按钮；已经阅读的时间、单词和笔记都会保存。
- 到时会自动结束、展开本轮结果，并按设置播放提示音。
- 正在运行时不能直接结束、重置或退出，也没有独立的展开按钮；需要退出时先暂停。

窗口获得焦点时，空格可以开始或暂停，Esc 可以暂停。输入笔记时这些按键用于文本编辑。电脑睡眠期间仍会消耗倒计时；需要离开时请先暂停。

## 章节与每日统计

三个无文字方框从左到右依次代表**引言、模型、发现**。读完一节后勾选对应方框，播放彩带庆祝；取消误勾会撤回对应计数。

「下一篇 →」会保留已读部分，清空三个方框并开始记录新论文，不中断计时，也不要求上一篇全部读完。下一轮计时保留当前论文；已经换论文时请点击「下一篇」。

未运行时，正常窗口显示今天已读分钟数与三类章节完成数量。只累计实际运行时间，暂停不计入；提前结束也保留已读时间。记录按电脑本地日期统计，并跨次保留。

## 随手笔记

迷你模式下点击「笔记」，直接展开多行文本框，计时继续进行。再次点击可收起；收起不会清空内容。

输入停顿约 450ms 后自动保存到本机，保存状态显示在文本框上方。开始前的笔记作为草稿带入下一轮。结束时展示本轮笔记，并生成 **本轮笔记.txt** 与 **本轮汇总.txt**；重新打开程序后仍可查看上一轮内容。

正常结束或退出会保存最新文本。遇到断电或强制结束进程，恢复的是最后一次已经保存的记录；请留意「保存中…」「已保存」或「保存失败」提示。

## 专注保护

仅在**正在计时且未暂停**时生效。允许 Zotero、Windows 文件管理器和常见浏览器，以及计时器自身。

切到其他普通前台应用时，程序立即尝试将其最小化，同时计时器轻跳、闪烁红色边框。不会关闭应用或处理未切到前台的后台窗口。暂停或结束后立即解除限制。

系统锁屏、凭据与安全界面不拦截；更高权限的应用可能受 Windows 权限限制而无法最小化。

## 单词与翻译

计时期间，在允许的阅读应用里选中一个**英文单词并复制**，程序自动收集并在后台译为中文。仅接收单个英文词，支持连字符和内部撇号；忽略句子、数字、网址、中文和图片。同一轮重复复制同一词只保留一条。

成功释义在悬浮窗显示 10 秒，多词按顺序展示。暂停期间不收集新词；开始或继续前剪贴板已有内容不会被倒查。

翻译由 MyMemory 在线提供，只发送识别出的单个英文词，不发送笔记、论文、窗口标题或其他剪贴板内容。释义可能不完全符合论文的专业语境。

结束后展示本轮所有单词。断网、超时或服务异常时，单词仍保存，汇总显示待重试数量；网络恢复后点击「重新翻译」。按钮会区分重新翻译、翻译中和翻译已完成，避免把固定按钮文字误当成失败状态。尚未结束的翻译返回后会更新列表和导出文件。

## 导出与扇贝单词

本轮结束后，文件自动保存在程序旁的 **词表\日期\本轮目录**。点击「导出词表」可打开文件夹；程序目录无法写入时，会尝试本地应用数据目录。

- **纯单词-扇贝用.txt**：UTF-8，每行一个词，不带释义或编号；包含尚未翻译成功的词。也可点击「复制纯单词」。
- **中英词表.csv**：包括单词、中文释义、翻译状态、论文序号与收集时间。
- **中英词表.tsv**：无表头，每行是英文、制表符和中文，只包含翻译成功的词。
- **本轮笔记.txt**：保留完整的中文、多行笔记。
- **本轮汇总.txt**：汇总本轮阅读时长、单词与笔记。

扇贝当前 App 的文件导入入口尚未验证。这里只提供纯单词 TXT 和复制功能，供其支持的添加方式使用；不承诺 CSV / TSV 可直接导入，不会登录或自动同步扇贝账号。

## 本地记录

设置保存在 %LOCALAPPDATA%\ReadingFocusTimer\settings.xml，阅读统计、笔记与单词保存在同目录的 reading-data.xml，并保留上一份备份。保留该文件夹即可保留历史。程序没有账号、自动开机启动、遥测或自动同步。

发行包只包含程序和说明，不包含任何个人词表、笔记或阅读数据。源码项目的构建与检查方法见仓库 README.md。
