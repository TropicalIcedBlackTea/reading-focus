# 文献专注 1.0

首个正式发行版，面向 Windows 10 / 11，使用 .NET Framework 4.8。下载 `ReadingFocus-1.0-win.zip`，解压后双击 `文献专注.exe` 即可使用。

## 功能

- 置顶悬浮倒计时：25 / 45 / 60 分钟与自定义时长，自动切换迷你与正常模式。
- 三个章节方框、勾选彩带庆祝、随时切换下一篇，以及每日阅读分钟与章节数量统计。
- 迷你窗口随手写笔记，约 450ms 自动保存；结束后展示、导出，重启保留上一轮笔记。
- 专注期间限制普通前台应用为 Zotero、文件管理器和常见浏览器；切到其他应用时尝试最小化，并跳动、闪红边提醒。
- 复制单个英文词后后台翻译，成功释义展示 10 秒；结束后汇总，支持失败重试与 TXT / CSV / TSV 导出。
- 更清晰的任务栏图标，包含高分辨率图标资源。

## 本次整理与修复

- 合并重复的结束 / 重置操作，只保留暂停后的「结束本轮」；计时中没有直接结束或展开按钮。
- 翻译重试按钮按处理状态显示，避免固定的「重试失败」文案造成误解。
- 保存阅读笔记，结束时输出独立笔记文件与完整汇总。
- 整理独立源码项目、构建脚本、隔离检查与发行打包脚本；正式程序不包含测试入口。

## 数据与使用范围

设置和阅读历史保存在本机 `%LOCALAPPDATA%\ReadingFocusTimer`。在线翻译只向 MyMemory 发送识别出的单个英文词，不上传笔记或论文。

扇贝目前提供纯单词 TXT 和复制方式，当前 App 导入入口未验证，不承诺自动同步。翻译依赖网络及第三方服务可用性，失败单词会保留，可稍后重试。

发行 ZIP 仅包含程序、使用说明和本发行说明，不包含个人笔记、词表、历史或测试数据。项目许可证待作者指定。
