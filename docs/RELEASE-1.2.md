# 文献专注 1.2

面向 Windows 10 / 11（.NET Framework 4.8）。下载 `ReadingFocus-1.2-win.zip`，解压后双击 `文献专注.exe`。

## 新功能

- **多张释义卡片同时显示**：连续查询的单词不再排队等待，每张卡片各自停留 10 秒，最新的在最上方；重复查询会刷新该词的卡片，点击卡片可提前收起。
- **永久生词本**：查过的单词跨轮次、跨重启保留，记录查询次数与时间。在「词表」中切换「本轮 / 生词本」，生词本支持搜索与移除，并同步导出为 `词表/生词本.csv` 和 `生词本-扇贝用.txt`。以前各轮收集的单词升级后自动并入。
- **词典扩充**：学术词表新增约 700 条经济学与计量术语（理论、产业组织、贸易、宏观、金融、劳动与发展、因果推断），总数约 6800 条；另新增约 1.5 万条通用词汇，按真实语料词频选取、经 WordNet 过滤人名与非词，释义逐条编写，学术或正式用法在前。
- **构词提示**：词典没有、但由已知词加常见前缀、-ness / -less 或连字符组成的词，显示标注「〔构词〕」的拆解。

## 调整

- CSV 的「词典」列新增「构词推测」。
- 旧版本中词典未收录的单词，打开后自动用新词典重新查询。

## 数据

设置和阅读历史保存在本机 `%LOCALAPPDATA%\ReadingFocusTimer`，与 1.0 / 1.1 兼容。程序不联网。发行 ZIP 包含程序、使用说明、本发行说明和许可证。
