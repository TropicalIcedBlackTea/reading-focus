# 文献专注 1.1

面向 Windows 10 / 11（.NET Framework 4.8）。下载 `ReadingFocus-1.1-win.zip`，解压后双击 `文献专注.exe`。

## 新功能

- **内置学术词典**：复制单词后直接显示中文释义，不再依赖在线翻译。词典侧重论文用词，覆盖学术词表、研究方法与统计 / 计量术语、经济与社会科学常用词和常见缩写。
- **跨行单词识别**：PDF 中跨行选中的单词（行尾连字符、换行或空格拆分、ﬁ / ﬂ 连字、软连字符、脚注数字）还原为一个词；复数、时态与英式拼写归并到词条原形。
- **开始即清场**：开始或继续计时时，立即最小化文件资源管理器、浏览器和 Zotero 以外的应用窗口。

## 界面

- 重新设计的界面：统一的配色、字体与图标，分段时长选择，迷你窗口带进度条。
- 精简提示文字：去掉自动保存、收录倒计时等说明，只在保存或导出失败时提示。
- 迷你窗口显示本轮词数；拦截应用时显示被最小化的应用名称。
- 词表中未收录的单词以浅色「词典未收录」标出。

## 调整

- 移除 MyMemory 在线翻译与「重新翻译」按钮，程序不再联网。
- CSV 第三列改为「词典」（已收录 / 未收录）；TSV 只包含有释义的词。
- 1.0 中翻译失败或中断的单词，打开后自动改用内置词典查询。

## 数据

设置和阅读历史保存在本机 `%LOCALAPPDATA%\ReadingFocusTimer`，与 1.0 兼容。发行 ZIP 仅包含程序、使用说明和本发行说明。项目许可证待作者指定。
